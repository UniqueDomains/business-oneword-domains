## ⚠️ Methodology and caveats

This set is broad and extension-heavy, centered on commercial terms such as business, company, startup, trade, exchange, management, project, and support. Sample domains like exchange.uk, startup.im, trade.cool, company.garden, and startup.trading show that the keyword theme is business-focused, but quality varies widely by TLD and context. For founders, the main question is whether the full name feels credible, memorable, and ownable now. For investors, the key is whether the ask leaves room for resale and whether the extension supports real end-user demand. With a median ask of $1,881, careful filtering by commercial clarity and renewal profile matters more than chasing volume.

- Check if the full name sounds credible, not just the keyword
- Compare ask price to TLD quality and likely buyer depth
- Avoid names that create obvious trademark or usage friction
- Favor clear pairings like exchange.uk over awkward extensions
